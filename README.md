# Portfolio Website — Rebuild

Rebuild of Jayam Patel's portfolio on branch `rebuild/mission-control`.

- **Stack:** Next.js 15 (App Router) + TypeScript + Tailwind CSS + Framer Motion
- **Package manager:** pnpm

This is currently a scaffold only — no design/UI has been implemented yet. See
[`docs/BUILD-SPEC.md`](docs/BUILD-SPEC.md) for the canonical build brief and
[`docs/DESIGN-DIRECTION.md`](docs/DESIGN-DIRECTION.md) for the locked creative direction.

The previous static site has been archived under [`legacy-static/`](legacy-static/).

## Development

```bash
pnpm install
pnpm dev
```
